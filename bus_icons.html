Leaflet.js Integration Guide

To use these highly optimized SVGs in your map, simply copy the SVG code and inject it via Leaflet's L.divIcon:

// 1. Paste the copied SVG string here
const busIconSvg = `<svg viewBox="0 0 240 320" ...>...</svg>`;

// 2. Create a DivIcon
const modernBusIcon = L.divIcon({
    className: 'custom-bus-marker',
    html: busIconSvg,
    iconSize: [45, 60], // Scales perfectly without losing quality
    iconAnchor: [22.5, 30] // Centers the icon on the coordinate
});

// 3. Add to map
L.marker([lat, lng], { icon: modernBusIcon }).addTo(map);
